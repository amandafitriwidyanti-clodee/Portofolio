# Portofolio Pribadi - Amanda Fitri Widiyanti

Website portofolio single-page responsif yang dibuat menggunakan HTML5, CSS3, JavaScript murni, dan Bootstrap 5. Didesain secara khusus untuk memenuhi tugas mata kuliah Pemrograman Web, dengan tema teknologi cerdas (IoT & Embedded Systems) berbalut desain modern dan elegan.

## Teknologi yang Digunakan
* HTML5
* CSS3 (Custom Styles & Variables)
* JavaScript (Vanilla JS untuk DOM manipulasi)
* Bootstrap 5.3.2 (via CDN)
* Bootstrap Icons (via CDN)
* Google Fonts (Poppins & Inter)
* AOS (Animate on Scroll) Library

## Cara Menjalankan Secara Lokal
1. Ekstrak atau clone folder proyek ini.
2. Pastikan file tersusun dengan struktur yang benar (index.html, css/, js/, assets/).
3. Buka file `index.html` menggunakan web browser pilihan Anda (Google Chrome, Firefox, dll).
4. Pastikan perangkat terhubung ke internet agar resource dari CDN (Bootstrap, Fonts) dapat dimuat.

## Kustomisasi Aset
* **Foto Profil:** Ganti file `assets/images/profile.jpg` dengan foto milik Anda. Jika belum ada, sistem akan menampilkan avatar *fallback* otomatis dari UI-Avatars.
* **Logo Navbar:** Buka baris 37 di `index.html` dan *uncomment* kode `<img>` jika ingin menggunakan logo *image*, atau biarkan dalam bentuk teks.
* **CV:** Letakkan file PDF di `assets/documents/cv-amanda.pdf`.
